# Xochimarket

## Descripción
Xochimarket es una plataforma de comercio electrónico diseñada para facilitar la compra y venta de productos en línea. El proyecto tiene como objetivo ofrecer una experiencia intuitiva y eficiente tanto para usuarios compradores como para vendedores.

## Funcionalidades principales
- Crear cuenta e iniciar sesión
- Ver productos disponibles
- Buscar productos por nombre o categoría
- Agregar productos al carrito
- Realizar compras fácilmente
- Administrar productos y usuarios desde un panel

## Tecnologías utilizadas

### Frontend
- **HTML5, CSS3 y JavaScript**
- **React.js** – Librería para construir interfaces de usuario dinámicas.
- **Tailwind CSS** – Framework de utilidades para estilos modernos y responsivos.
- **React Router** – Para el manejo de rutas dentro de la aplicación.

### Backend
- **Node.js** – Entorno de ejecución para JavaScript del lado del servidor.
- **Express.js** – Framework minimalista y eficiente para crear APIs REST.

### Base de Datos
- **MongoDB** – Base de datos NoSQL, ideal para prototipos rápidos y esquemas flexibles.
- **Mongoose** – ODM para modelar y gestionar los datos de MongoDB desde Node.js.

## Instalación y ejecución

1. Clonar el repositorio:
    ```bash
    git clone https://github.com/tunombreusuario/xochimarket_repo.git
    ```

2. Instalar dependencias:
    ```bash
    npm install
    ```

3. Configurar variables de entorno (si aplica):
    ```env
    # Agrega aquí variables como DB_HOST, PORT, etc.
    ```

4. Ejecutar la aplicación:
    ```bash
    npm start
    ```

## Estructura del proyecto
- `/src` - Código fuente principal del frontend
- `/server` - Código del backend y rutas de la API
- `/public` - Archivos estáticos
- `/docs` - Documentación del proyecto
- `/tests` - Pruebas automatizadas
