# Xochimarket

## Descripción
Xochimarket es una plataforma de comercio electrónico diseñada para facilitar la compra y venta de productos en línea. El proyecto tiene como objetivo ofrecer una experiencia intuitiva y eficiente tanto para usuarios compradores como para vendedores.

## Funcionalidades principales
- Registro y autenticación de usuarios
- Navegación y búsqueda de productos
- Gestión de carrito de compras
- Proceso de pago seguro
- Panel administrativo para gestión de productos y usuarios
